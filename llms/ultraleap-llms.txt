# Ultraleap

> Ultraleap Limited (Bristol, UK) makes hand-tracking cameras (Leap Motion Controller 2, Stereo IR 170, 3Di) and mid-air ultrasonic haptics. Its developer surface is a locally installed Hand Tracking Software (Hyperion V6) with a native C API called LeapC, plus Unity and Unreal plugins, an implicit OpenXR API layer, Python bindings, a LeapJS-compatible WebSocket server and the TouchFree touchless-interaction tooling. There is no hosted HTTP API, OpenAPI or base URL. In 2025 the company announced it is joining ROLI.
